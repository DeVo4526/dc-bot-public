## 功能一覽

### AI 聊天（Gemini）

訊息裡打「**悠筑**」/「**小筑**」，或直接 **@** 這個 bot，就會回覆，不用打指令，像平常聊天一樣。每個人在每個頻道都有各自獨立的對話記憶，不會互相干擾；同一個人不管在哪個頻道，好感度都是同一份，會慢慢累積、也會隨時間自然變淡。

| 指令 | 說明 |
|------|------|
| `/chat_reset` | 清除你自己在這個頻道的聊天記憶，重新開始對話 |
| `/my_memory` | 查看悠筑對你的印象記憶（好感度、心情、印象筆記、提過的人） |
| `/todo add` `/todo list` `/todo done` | 不透過聊天，直接管理待辦事項 |

聊天中可以直接請她幫忙：

- **設定提醒**：「10分鐘後提醒我喝水」「4點54分提醒我開會」，會真的建立排程，跟 `/schedule` 是同一套系統，之後也能用 `/schedule list` 查到
- **查詢提醒**：問她「還有哪些提醒」，她會查真實資料回答，不會亂講
- **問現在幾點**
- **查天氣**：「東京現在天氣怎樣」，用免費、不需金鑰的公開氣象 API
- **記事情**：「幫我記一下要買牛奶」——沒有明確時間點的事，先記著，之後問起或聊到相關話題會提起
- **記生日/紀念日**：之後每年到那一天她會主動祝福

**看得懂圖片**：訊息附圖時她會自然回應內容，不需要額外說明。

**多人群聊**：她分得清楚頻道裡誰在跟誰說話，如果你是用 Discord 的「回覆」功能接續某則訊息，她也認得出你接的是誰講的話。

> 頻道裡的近期對話（包含其他人的訊息）可能會被當作參考內容送給 Gemini，讓她對頻道當下在聊什麼有基本感知；請留意這一點。

需要設定 `GEMINI_API_KEY` 才能使用這部分功能（包含下面的 RPG 跑團）。

### 排程提醒

| 指令 | 說明 |
|------|------|
| `/schedule add` | 新增定時提醒，參數：`time`（24 小時制，如 `20:30` 或 `2030`）、`repeat`（每日重複／一次性）、`text`（提醒內容，可留空） |
| `/schedule remove` | 刪除自己的排程，`job` 參數會自動帶出你目前的排程清單供選擇（免記 ID） |
| `/schedule list` | 查詢自己目前所有排程（僅自己可見） |

- 支援每日重複和一次性兩種類型
- 提醒時會顯示觸發當下的 Discord 暱稱
- 每個人只能查詢、刪除自己建立的排程

### 狼人殺

#### 開局流程

```
/werewolf              → 建立大廳（指令者為房主）
.join                  → 其他玩家加入（至少 4 人才能開始）
.ww_roles 狼2 預1 女1 守1 白1  → 房主自訂角色組合（可略過，使用預設；守衛/白痴預設不會出現，要自訂才會加入）
.start                 → 房主開始遊戲
.ww_cancel             → 房主取消大廳
```

#### 預設角色分配

| 玩家人數 | 狼人 | 預言家 | 女巫 | 獵人 | 村民 |
|----------|------|--------|------|------|------|
| 4–5 人   | 1    | 1      | —    | —    | 其餘 |
| 6–7 人   | 2    | 1      | 1    | —    | 其餘 |
| 8+ 人    | 2    | 1      | 1    | 1    | 其餘 |

#### 角色自訂格式

```
.ww_roles 狼2 預1 女1 獵0 守1 白1
```

關鍵字：`狼`（狼人）、`預`（預言家）、`女`（女巫）、`獵`（獵人）、`守`（守衛）、`白`（白痴）

守衛、白痴預設的角色分配（上面那張表）不會出現，只有房主用 `.ww_roles` 明確指定才會加入。

#### 遊戲流程

**夜晚（DM 私訊 bot）**

| 角色 | 行動 |
|------|------|
| 狼人 | 輸入目標編號投票殺人 |
| 預言家 | 輸入目標編號查驗陣營 |
| 守衛 | 輸入目標編號保護一人不被狼人殺死（不能連續兩晚保護同一人；如果守衛跟女巫同一晚救了同一個人，那個人還是會死——同守同救、該死還死） |
| 女巫 | `y`/`n` 決定是否救人，再輸入編號（或 `0` 跳過）毒人 |
| 獵人 | 死亡時 DM 輸入目標編號射殺 |

**白天（頻道公開）**

1. bot 公告昨夜死亡玩家
2. 120 秒自由討論
3. 60 秒投票：輸入要放逐的玩家編號
4. 票數最高者出局，若平局則無人出局；如果出局的是**白痴**，第一次只會翻牌、不會死，但之後不能再投票（如果翻牌後又被放逐一次，第二次就會真的死亡）

**勝利條件**

- 村民陣營：所有狼人被消滅
- 狼人陣營：狼人數量 ≥ 村民數量

| 階段 | 時間 |
|------|------|
| 夜晚行動（狼 / 預 / 守） | 60 秒 |
| 女巫每步 / 獵人射擊 | 30 秒 |
| 白天討論 | 120 秒 |
| 投票 | 60 秒 |

### RPG 跑團

悠筑當說書人，帶大家一起玩一場文字冒險，不是隊伍裡的角色。

#### 開局流程

```
/rpg [theme] [bio]     → 建立大廳（指令者為房主，可留主題／背景，也可以留自己的角色自介）
.join [角色自介]        → 其他玩家加入（1~6 人，1 人也能玩，悠筑帶你玩單人冒險），自介可留可不留
.start                 → 房主開始遊戲
.rpg_cancel            → 房主或管理員取消
.rpg_status            → 隨時查看目前狀態（第幾幕、每人數值），不限房主
```

#### 遊戲機制

- 每輪她會生成場景敘述＋2~4 個選項，全員按鈕投票（多數決）
- 每人有**力量／敏捷／智慧／魅力**四維屬性（加入時隨機分配），遇到有風險的選擇會擲骰決定結果；擲出最大點數一定大成功、擲出 1 一定大失敗
- 一場冒險大概十幾到二十幕，會自然收尾，不會無限進行下去
- 遊戲進度完全存在記憶體，不會留存，中斷或重開就直接捨棄
